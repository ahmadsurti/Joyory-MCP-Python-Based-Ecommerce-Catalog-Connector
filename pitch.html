The Problem
Beauty shopping is broken by information overload

A customer buying a vitamin C serum needs to compare ingredients, ratings, skin type compatibility, and price — across multiple products, across multiple browser tabs, entirely on their own. The current search-scroll-click-read loop is high friction and high abandonment. Customers don't leave because the product is wrong. They leave because the experience failed them.

The Solution
Joyory's catalog as a conversational AI tool

Joyory MCP is a live product intelligence server that connects Claude AI directly to Joyory's product database using the Model Context Protocol — the new open standard for AI tool integration.

Key Engineering Insight
We didn't guess the API — we discovered it

Joyory is a React SPA. Every URL returns the same HTML. There is no public API documentation. Rather than guessing, we built an automated discovery engine using Playwright that analyzes real browser behavior, scores 102 API candidates found inside Joyory's JS bundle, and auto-generates the server configuration. This is how we found the real API host: beauty.joyory.com.

Challenges & Solutions

Challenge

Challenge

Solution
Inspected the installed package directly to discover the real v2 API surface.

Solution
